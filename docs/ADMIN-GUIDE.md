## Getting Started

The Pack 3472 website uses **Netlify CMS** for easy content management. No technical skills required!

### Accessing the Admin Panel

1. Visit: `https://pack3472.org/admin/`
2. Click "Login with Netlify Identity"
3. Enter your pack leader credentials
4. You'll see the admin dashboard with content options

### Your Dashboard

The dashboard shows:

- **Events** - Add/edit pack meetings, campouts, activities
- **Announcements** - Post news and updates
- **Galleries** - Upload and organize photos
- **Resources** - Manage downloadable files

## Adding Events

Events appear on the calendar page and homepage.

### Step-by-Step

1. Click **"Events"** in the left sidebar
2. Click **"New Event"** button
3. Fill in the form:
   - **Title**: Name of the event (e.g., "Spring Campout")
   - **Date**: Event date
   - **Time**: Start time (e.g., "6:30 PM")
   - **Location**: Where it's happening
   - **Description**: Details about the event
   - **Event Type**: Pack Meeting, Den Meeting, Campout, etc.
   - **RSVP Link** (optional): Google Form link for signups
4. Click **"Publish"**

### Tips

- Use clear, descriptive titles
- Include what to bring in the description
- Add RSVP deadline if applicable
- Set as "Draft" to preview before publishing

## Posting Announcements

Announcements appear on the homepage and news page.

### Step-by-Step

1. Click **"Announcements"** in sidebar
2. Click **"New Announcement"**
3. Fill in:
   - **Title**: Announcement headline
   - **Content**: Your message (use the editor for formatting)
   - **Priority** (optional): Mark important announcements
4. Click **"Publish"**

### Best Practices

- Keep titles short and clear
- Use bullet points for lists
- Mark time-sensitive info as "High Priority"
- Include links where relevant

## Uploading Photos

Share pack activities through photo galleries.

### Step-by-Step

1. Click **"Galleries"** in sidebar
2. Click **"New Gallery"**
3. Fill in:
   - **Title**: Gallery name (e.g., "Pine Wood Derby 2024")
   - **Date**: Event date
   - **Description**: Brief overview
4. Click **"Add Photos"**
5. Select multiple images from your computer
6. Add captions if desired (first names only, no last names!)
7. Click **"Publish"**

### Photo Guidelines

⚠️ **IMPORTANT - Youth Protection**

- Use first names only (no last names)
- No photos that could identify scouts' home locations
- Get parent permission before posting
- Follow BSA youth protection policies

### Technical Tips

- Recommended size: 1920x1080 pixels or smaller
- Formats: JPG or PNG
- Keep file sizes under 5MB each
- Photos will be automatically optimized

## Updating Pack Information

### Meeting Times and Location

1. Go to **"Pack Info"** section
2. Edit meeting day, time, and location
3. Click **"Save"**
4. Changes appear on homepage and footer

### Leadership Roster

1. Go to **"Leaders"** section
2. Add/edit/remove pack leaders
3. Include role (Cubmaster, Den Leader, etc.)
4. Add photo and contact info
5. Click **"Save"**

### Den Information

1. Go to **"Dens"** section
2. Add/edit den details
3. Include den leader and meeting times
4. Click **"Save"**

## Managing Resources

Add downloadable files like permission slips, handbooks, and calendars.

### Step-by-Step

1. Click **"Resources"** in sidebar
2. Click **"Add Resource"**
3. Fill in:
   - **Title**: File name
   - **Category**: Forms, Handbooks, Calendars, Policies
   - **File**: Upload PDF or DOC file
4. Click **"Publish"**

### Organizing Resources

- Use clear, descriptive titles
- Choose correct category
- Date files if applicable (e.g., "2024 Permission Slip")
- Remove outdated files regularly

## Troubleshooting

### "I can't log in"

- Check your email and password
- Request password reset if needed
- Contact webmaster for access issues

### "My changes aren't showing"

- Wait 2-3 minutes for site to rebuild
- Refresh your browser (Ctrl+F5 or Cmd+Shift+R)
- Check if you clicked "Publish" (not just "Save")

### "I uploaded a photo but it's too big"

- Use photo editing software to resize
- Try compressing the file
- Maximum recommended: 5MB per photo

### "I made a mistake"

- Go back to the content item
- Click "Edit"
- Make corrections
- Click "Publish" to update
